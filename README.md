# RASR: 영역 적응형 초해상도

**기간:** 2025.05.01 – 2025.06.01

## 개요

한 번에 128²픽셀만 찍을 수 있는 UAV가 128² 세 장(512² 전체의 약 19%)으로 512² 영상을 얻도록 한다.
높은 고도에서 전체를 찍은 영상을 서버가 2배로 키우고, 영역 선택 모델이 다음 촬영에서 볼 패치를 골라
UAV가 낮은 고도에서 그 영역만 찍으면 키운 영상에 합성한다. 이 과정을 128² → 256² → 512² 두 단계로
반복한다. 설계 이유와 전체 결과는 [`docs/experiment-log.md`](docs/experiment-log.md)(이하 로그)에 있다.

| 역할 | 모델 | 구조 |
| --- | --- | --- |
| 복원 (2배) | SRCNN | 보간 후 합성곱 3층 (기준선) |
| | TransConv | transposed conv 한 번 |
| | UDUCNN | 업 → 다운 → 업 |
| | UUDCNN (최종) | 업 → 업 → 다운 |
| 영역 선택 | IMCNN (최종) | 한 해상도에서 중요도 맵 예측 |
| | MRIMCNN | 원본·½·¼ 해상도의 중요도 맵 합성 |

## 결과

모든 모델은 COCO train2017 3,000장으로 50에폭 학습했고, val2017 500장의 평균 PSNR로 평가했다.

### 복원 모델 (128² → 256²)

| 모델 | SRCNN | TransConv | UDUCNN | UUDCNN |
| --- | --- | --- | --- | --- |
| 파라미터 | 56K | 209K | 264K | 376K |
| 평균 PSNR (dB) | 28.21 | 30.78 | 30.99 | **31.10** |

### 패치 크기 (UUDCNN 위, 128² → 256²)

<div align="center">

<img src="assets/region_sweep.png" alt="패치 크기별 영역 선택 결과" width="640">

</div>

- 촬영 예산은 고정(`K = 128² / 패치 크기²`)이다. 두 마스크 모두 패치 크기 2에서 가장 높고, 모든 패치 크기에서
  랜덤 선택보다 높다.

### 두 단계 복원 (128² → 256² → 512²)

| 파이프라인 | UUDCNN만 두 번 | + 랜덤 선택 | + IMCNN | + MRIMCNN |
| --- | --- | --- | --- | --- |
| 평균 PSNR (dB) | 27.15 | 28.15 | **31.53** | 31.57 |
| 마스크 파라미터 | — | — | **5.5K** | 16.6K |

- 학습된 선택은 같은 예산을 랜덤으로 쓸 때보다 3.4dB 높다.
- MRIMCNN이 0.04dB 높지만 파라미터가 약 3배라서, 파라미터 대비 성능이 나은 IMCNN을 최종으로 골랐다.
